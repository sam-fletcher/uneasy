---
title: "How should an owner see that an asset's name can be renamed?"
---

On your own retinue the asset's name is a button: tap it to rename. It has never had a visible
control, only a border that appears on hover (which a phone doesn't have). The rulings put a box on
what a player presses, and a retinue's tiles are pieces, so a name with a box around it would be a
second box inside the tile.

I **left it as it was**, a name that reads as a title and is pressable, with a 44px target, and
a border on hover and a ring on focus. That keeps the tile quiet but leaves renaming undiscoverable
on a phone.

- **Is that acceptable, or should the owner get a visible control?** The options I can see: a small
  pencil beside the name (a new mark, which needs your sign-off), a "Rename" text button under it,
  or nothing, as now.
