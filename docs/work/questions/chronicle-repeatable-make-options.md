---
title: "Chronicle Histories: may the preparer pick the same make option more than once?"
---

On a make the preparer chooses as many options as the roll's result. The
handler treats the options as repeatable (two breaks, two invocations, the
same narrative option twice are all accepted), and the panel never hides a used
option. The book says "choose a number of these equal to your result" and
doesn't say whether each may be chosen once only. (Make Introductions' book text
does say to pick a different option each time; this plan's doesn't.)

Should a repeat be allowed? If not, the panel should disable used options and
the route should refuse a repeat.
