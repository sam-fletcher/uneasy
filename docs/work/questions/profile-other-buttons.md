---
title: "On the profile, should every other button besides Join be a secondary one?"
---

The brief for this piece was: Join greyed out until a code is typed, and "Create a new table" a
secondary button, so that Join is the only filled button on the page. The page had more filled gold
buttons than those two: the Edit buttons for the player name and password, Turn on / Turn off for
push, and Send feedback. The mockup stops above them, so none is shown or ruled.

To leave Join as the only filled button, this piece made them secondary: Edit, Turn on / Turn off and Send
feedback. Save (while a name or password is being edited) stays the main button, since it is the one
thing to do in that moment, and Retry stays main on the load-error screen where it is the only
button. The Edit buttons also went from 36px tall to the 44px touch minimum.

Say if you'd rather any of these keep the filled look. It is a one-word change per button.
