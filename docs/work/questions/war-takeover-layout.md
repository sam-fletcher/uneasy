---
title: "The owed-costs list in a war's play area: is “against” the right word?"
---

While a cost of battle is due, the war's panel lists every payer and the opponent they owe, in the
order they pay, with each player's shape. The old line was "Outstanding (payer → opponent), in
reverse-power order: Wren → otto; otto → Wren", and a typed arrow draws from a different font on each
phone, so each line is now a label ("Owed this row, in order") over lines like "▲ Wren against ◆ otto".

"Against" is my wording and the one open copy question. Does it read right for a payment, or would you
rather say something else ("Wren pays otto", "Wren owes otto")? It is one string in
`plans/war/CostOfBattle.svelte`, and the e2e specs that read it (`make_war.spec.ts`, "owed-line").
