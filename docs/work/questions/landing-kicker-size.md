title: "Should the landing kicker be the label size or the small size?"
---

The line above the landing title, "Adam Bell's", is set in the display face with wide
tracking. The rules say uppercase labels take the 12px label size, but the display face
is thin at that size. It was set at the 14px small size, which is closer to what it was
before the migration.

Which size should it take: 12px to follow the label rule to the letter, or 14px so the
display face holds up on a phone?
