---
title: "Should \"Speaking as\" show when there is only yourself to speak as?"
---

The composer has a "Speaking as" control above the message box. Today it appears only in a
scene where you control a character, because that is the only time there is a choice: outside a
scene you can speak only as yourself, so the control would be a button with one option.

The signed-off chat mockup draws it with just the player's own name and shape ("Speaking as ◆ Ash"),
though that picture is of a table in the middle of a scene, where the control is already there.

- Keep it only when there is a choice (what is built)?
- Or always show it, as a plain line saying who you are speaking as, and a control only in a scene?
  That tells you who the message will come from even when you cannot change it, at the cost of one
  more line above the box all the time. If it is always there but inert, it should not be drawn
  as a control (a box marks a thing you can touch).
