---
title: "Clandestinely Liaise: should the asset that holds the meeting's secret be public?"
---

Secrets We Keep hides which asset each player nominated until both have, but the action log posts "X entrusted the meeting's secret to <asset>" the moment each pick lands, so the pick is public anyway. Should the holder stay secret (drop the asset name from the log line and keep the mask), or is it public (drop the mask)? Pinned as current behaviour, both halves, in `frontend/tests/e2e/clandestinely_liaise.spec.ts`; whichever way this is ruled, one assertion there goes.
