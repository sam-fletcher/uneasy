# Hand-over notes

One file per work session, `<session-name>.md`, committed on that session's
branch. Each note says what changed and why, how it was verified, behaviour
changes worth a look before merging, open questions for the owner, and
anything noticed but deliberately not fixed. Open questions also go in
[../TRACKER.md](../TRACKER.md).

Paraphrase the rulebook; never quote it verbatim — this repo is public.
