# Credits

Adapted from the [`wait-what`](https://github.com/mattpocock/skills/blob/main/skills/productivity/wait-what/SKILL.md)
skill in [Matt Pocock](https://github.com/mattpocock)'s
[skills](https://github.com/mattpocock/skills) repository (MIT licence): a
user-typed skill that asks for the last message again, with a little
context, in ASD-STE100 Simplified Technical English and the project's own
language from its glossary.

This version adds the owner's situation (learning web development), each
web term explained once by pointing at the part of Uneasy that does it,
what the message means for players or for the owner, and re-asking any
question the message held.
