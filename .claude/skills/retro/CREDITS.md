# Credits

Adapted from the [`retro`](https://github.com/mattpocock/skills/blob/main/skills/engineering/retro/SKILL.md)
skill in [Matt Pocock](https://github.com/mattpocock)'s
[skills](https://github.com/mattpocock/skills) repository (MIT licence): a
retrospective that improves the agent's environment rather than its code,
preferring an automated check over a written rule, and reporting candidates
most severe first.

This version names where this project's transcripts and existing guard
tests live, adds memory and the owner's time as categories, and asks for
evidence behind every finding.
