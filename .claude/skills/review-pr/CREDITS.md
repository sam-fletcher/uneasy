# Credits

Adapted from the [`code-review`](https://github.com/mattpocock/skills/blob/main/skills/engineering/code-review/SKILL.md)
skill in [Matt Pocock](https://github.com/mattpocock)'s
[skills](https://github.com/mattpocock/skills) repository (MIT licence):
reviewing on separate axes in parallel subagents with fresh contexts,
reporting the axes side by side rather than re-ranked, and a baseline of
code smells from Martin Fowler's *Refactoring* treated as judgement calls.

This version adds an axis for the game rules and the owner's design
principles, mechanical pre-checks including a public-repo scan, a check of
the PR's evidence, and the coordinator's send-back or mark-ready step.
