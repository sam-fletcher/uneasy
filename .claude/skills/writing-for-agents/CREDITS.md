# Credits

Adapted from the [`writing-for-agents`](https://github.com/mattpocock/skills/blob/main/skills/productivity/writing-for-agents/SKILL.md)
skill and its [`SKILL-MECHANICS.md`](https://github.com/mattpocock/skills/blob/main/skills/productivity/writing-for-agents/SKILL-MECHANICS.md)
in [Matt Pocock](https://github.com/mattpocock)'s
[skills](https://github.com/mattpocock/skills) repository (MIT licence):
pointers and their branches, context load against cognitive load, the
ladder of steps and reference with progressive disclosure, completion
criteria judged by clarity and demand, splitting by sequence or
invocation, leading words, stating the target instead of the ban, and
pruning (one home per meaning, the environment as a source of truth,
no-ops, sediment), plus the model- versus user-invoked choice and router
skills.

This version maps the levers onto this project's documents: which files
every session loads, where each meaning lives, memory index lines as
pointers, the skills' *Done when* convention, briefs and hook messages as
agent-read documents, a check preferred to a sentence, and the
public-repo and credit rules.
