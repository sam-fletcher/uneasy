# Credits

Adapted from a `git-commit` skill the owner shared, of unrecorded origin:
commit messages as the long-term home for intent, never inventing a
rationale, the rejected alternative as the most valuable line, messages
that stand on their own without session references, and an honest line
when nothing tests the change.

This version adds public-repo rules (nothing that points into the private
folder), recording the session's own calls openly instead of stopping to
ask, this repo's subject-line style, and tidying a branch with
`--force-with-lease`.
