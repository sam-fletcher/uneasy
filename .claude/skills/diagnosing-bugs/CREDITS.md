# Credits

Adapted from the [`diagnosing-bugs`](https://github.com/mattpocock/skills/blob/main/skills/engineering/diagnosing-bugs/SKILL.md)
skill in [Matt Pocock](https://github.com/mattpocock)'s
[skills](https://github.com/mattpocock/skills) repository (MIT licence): the
red-check-first discipline, shrinking, ranked falsifiable hypotheses, tagged
debug logs, and the regression-test seam check.

This version maps each way of building a check to this project's tools,
adds how to handle reports from live games, and lists the kinds of bug this
project has had before as starting hypotheses.
