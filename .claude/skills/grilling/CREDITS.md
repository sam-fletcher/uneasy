# Credits

Adapted from the [`grilling`](https://github.com/mattpocock/skills/blob/main/skills/productivity/grilling/SKILL.md)
skill in [Matt Pocock](https://github.com/mattpocock)'s
[skills](https://github.com/mattpocock/skills) repository (MIT licence): the
decision tree, asking the whole frontier per round, a recommended answer per
question worded so "yes" accepts it, and facts found by the agent rather than
asked.

This version adds reading the owner's existing rulings first, the reason
behind every recommendation, plain-language questions, and where each kind
of ruling gets recorded.
